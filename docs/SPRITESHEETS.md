# Folhas de Sprites

Atualmente, existem 3 folhas de sprite. Cada uma representando um personagem selecionável do jogo. Todas as folhas seguem a seguinte regra:

- 16px de largura
- 48px de altura
- 16x16 cada frame
- O primeiro frame (de cima pra baixo) deve ser reaproveitado como frame de `standing`, enquanto os 3 frames devem ser utilizados para fazer uma animação de `walking`

Os sprites dos personagens em questão são:

- `web/spritesheets/bobabao.png`
- `web/spritesheets/lixaredo.png`
- `web/spritesheets/tubarina.png`

Se houver demanda para novos spritesheets, liste-os neste arquivo.
